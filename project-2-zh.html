匯率自動化與多來源資料整合

問題

財務與會計團隊每日需要參考多家台灣銀行與政府機構的匯率資料， 以支援報表製作與帳務核對。過去以人工方式蒐集這些匯率， 不僅耗時且容易出錯，每天需耗費超過 30 分鐘的人力， 而隨著資料來源與下游報表數量增加，這個問題也愈趨嚴重。

解決方案

我建構了一套端到端的匯率自動化系統，自動從多家銀行與政府機構的 網站擷取每日與每月匯率，並運用 Selenium 與 Playwright 處理各種反爬蟲機制。 系統透過 MERGE 式 ETL 管線，將蒐集到的資料同步寫入 SQL Server 與 Oracle 兩套資料庫，確保各系統間的資料一致性；接著自動產出 Excel 報表， 並發送 Email 通知相關利害關係人，完全免除人工蒐集資料與整理報表的作業。

技術棧

  • Python
  • Selenium 與 Playwright（網頁爬蟲、反爬蟲處理）
  • SQL Server 與 Oracle（MERGE 式 ETL 管線）
  • Excel 報表產出
  • 自動化 Email 通知

我的角色

我獨立設計並建構了整套自動化管線 — 從資料來源的擷取邏輯， 到資料庫整合與報表發送，全程一手包辦。我也與財務團隊協調確認資料來源， 並訂定資料驗證與例外處理的商業規則。

成效／指標

  • 將每日人工處理時間從 30 分鐘以上縮短至 5 分鐘以內
  • 消除多家銀行與政府機構資料來源的人工登錄錯誤
  • 統一 SQL Server 與 Oracle 系統間的匯率資料標準
