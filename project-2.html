Exchange Rate Automation & Multi-Source Data Integration

Problem

Finance and accounting teams needed daily and monthly exchange rates from multiple Taiwanese bank and government sources to support reporting and reconciliation. Collecting these rates manually was slow, error-prone, and consumed over 30 minutes of staff time each day — time that scaled poorly as more source systems and downstream reports were added.

Solution

I built an end-to-end exchange rate automation system that scrapes daily and monthly rates from multiple bank and government websites, handling anti-bot measures using Selenium and Playwright. The system upserts the collected data into both SQL Server and Oracle databases through MERGE-based ETL pipelines, ensuring consistency across systems. It then automatically generates Excel reports and sends email notifications to relevant stakeholders, removing the need for any manual data collection or report assembly.

Tech Stack

  • Python
  • Selenium & Playwright (web scraping, anti-bot handling)
  • SQL Server & Oracle (MERGE-based ETL pipelines)
  • Excel report generation
  • Automated email notifications

Your Role

I designed and built the full automation pipeline end to end — from source scraping logic to database integration and report distribution. I also identified the source systems in coordination with finance stakeholders and defined the business rules for data validation and exception handling.

Impact / Metrics

  • Reduced daily manual processing time from 30+ minutes to under 5 minutes
  • Eliminated manual data entry errors across multiple bank and government sources
  • Standardized exchange rate data across SQL Server and Oracle systems
