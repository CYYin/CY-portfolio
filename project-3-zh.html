BPM 系統轉型 — 從 Domino 到現代化網頁平台

問題

公司核心的 BPM 生態系統已在 HCL Domino 上運行多年，累積了大量對業務至關重要的 資料與流程，但維護成本日益提高，擴充也愈發困難。此平台與現代系統的整合選項有限， 隨著組織數位轉型計畫的擴展，也愈來愈難以支撐系統的擴展需求。

解決方案

我主導了既有 HCL Domino BPM 生態系統的現代化工程，將業務資料與流程遷移至 現代化、可擴展的平台架構。新架構以 SQL Server 作為資料儲存層、Vue.js 打造前端體驗， 並以 Python 為基礎的 API 與微服務處理商業邏輯與系統整合。此次轉型使組織得以 擺脫封閉的既有平台，邁向開放、可維護且具擴充性的系統架構。

技術棧

  • HCL Domino（既有來源系統）
  • SQL Server
  • Vue.js
  • Python
  • REST API 與微服務

我的角色

身為專案經理，我訂定了遷移策略與架構方向，協調既有系統專家與新開發團隊之間的合作， 並管理分階段上線以降低對業務營運的衝擊。我全程負責確保遷移過程中的資料完整性， 並確保新平台與長期 IT 架構目標一致。

成效／指標

  • 成功將核心 BPM 流程從難以維護的既有平台遷出
  • 建立現代化、以 API 為核心的架構，為未來整合做好準備
  • 提升系統可維護性，降低對既有 Domino 專業人力的依賴

標籤

BPM HCL Domino SQL Server Vue.js Python 微服務
