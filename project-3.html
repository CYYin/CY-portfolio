Legacy BPM Modernization — From Domino to Modern Web Platform

Problem

A core BPM ecosystem had been running on HCL Domino for years, accumulating business-critical data and workflows that were increasingly costly to maintain and difficult to extend. The platform limited integration options with modern systems and made it hard to scale as the organization's digital transformation initiatives expanded.

Solution

I led the modernization of the legacy HCL Domino BPM ecosystem, migrating business data and workflows toward a modern, scalable platform architecture. The new architecture is built on SQL Server for data persistence, Vue.js for the front-end experience, and Python-based APIs and microservices for business logic and integration. This shift enabled the organization to move away from a closed legacy platform toward an open, maintainable, and extensible system architecture.

Tech Stack

  • HCL Domino (legacy source system)
  • SQL Server
  • Vue.js
  • Python
  • REST APIs & Microservices

Your Role

As Project Manager, I defined the migration strategy and architecture direction, coordinated between legacy system experts and the new development team, and managed the phased rollout to minimize business disruption. I was accountable for data integrity throughout the migration and for aligning the new platform with long-term IT architecture goals.

Impact / Metrics

  • Successfully migrated core BPM workflows off a legacy, hard-to-maintain platform
  • Established a modern, API-driven architecture ready for future integration
  • Improved system maintainability and reduced dependency on legacy Domino expertise
