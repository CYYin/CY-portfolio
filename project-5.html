HCL Notes to SQL Server BPM Data Migration & Sync Platform

Problem

Over 300 BPM forms containing years of historical business data lived in HCL Notes 12, a legacy platform with limited reporting and integration capabilities. Migrating this volume of forms — each with different field structures, bilingual labels, and Master/Detail relationships — to a modern database manually would have been extremely time-consuming and error-prone, and the business needed a way to keep the two systems in sync during the transition period.

Solution

I built an end-to-end data migration and sync platform that automates historical data migration for 300+ BPM forms from HCL Notes 12 to SQL Server via the Domino REST API (DRAPI). The platform uses the Claude AI API to semantically infer field mappings — reconciling Chinese and English labels, data types, and Master/Detail structures — and auto-generates Excel mapping sheets for business review before any data moves. Once mappings are approved, the system auto-creates target tables in SQL Server and runs the full-history data import. To keep both systems aligned going forward, I implemented a continuous incremental sync mechanism using unread-document checkpointing, SQL Server UPSERT logic (insert/update by notes_unid), soft-delete handling, and sync audit logging with email alerting for failures.

Tech Stack

  • Python
  • Domino REST API (DRAPI)
  • Claude AI API (semantic field-mapping inference)
  • SQL Server (UPSERT-based sync, soft-delete handling)
  • ETL pipelines for historical & incremental data migration
  • Automated audit logging & email alerting

Your Role

I designed and built the entire migration and sync platform, including the AI-assisted field mapping process and the incremental sync architecture. I also coordinated with business owners of each of the 300+ forms to review and validate the AI-generated mapping sheets before migration.

Impact / Metrics

  • Automated migration of 300+ BPM forms without manual field-mapping effort
  • Enabled continuous, reliable sync between HCL Notes and SQL Server during transition
  • Reduced risk of data loss through checkpointing, soft-delete handling, and audit logging
